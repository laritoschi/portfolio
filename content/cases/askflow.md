###### Context & Challenge
## AskFlow is a drag-and-drop conversational AI automation tool for the hospitality industry.

{% twoCol %}

  {% wrap %}
  ### Main problem

  Post-launch adoption was constrained by a high cognitive load and intimidating logic blocks that required programming knowledge. Users could build powerful automations, but the experience felt too technical for non-developers. The result was slow activation, rising support demand, and a weak first impression.
  {% endwrap %}

  {% wrap %}
  ### Design & business goals

  - Shorten time-to-perceived ROI
  - Reduce support tickets
  - Lower cognitive load for non-technical users
  - Impact account upgrades through simplified agent activation
  {% endwrap %}

{% endtwoCol %}

###### Discovery & Strategy
## We aligned the product triad around what mattered most: reducing friction while preserving flexibility.

{% cardRow 3 %}

  {% wrap %}
  ### Journey Mapping

  Mapped the activation path to uncover where external and internal users got stuck and what assumptions were missing.
  {% endwrap %}

  {% wrap %}
  ### Activation Team Workshop 

  Aligned internal teams around opportunities worth prioritizing first.
  {% endwrap %}

  {% wrap %}
  ### CSD Matrix

  Used a matrix of Certainties, Suppositions, and Doubts to focus the effort on high-confidence bets.
  {% endwrap %}

{% endcardRow %}

> **Key insight:** Even custom workflows share common baseline structures. A standard Agent Template Library could reduce friction without removing flexibility.

###### Design process
## From paper sketches to a testable wireframe, refined through group brainstorming.

{% twoCol %}

  {% wrap %}
  ### Paper sketches

  I first sketched the concept by hand to think through and quickly validate the idea with the product triad.
  {% endwrap %}

  {% wrap %}
  ### Figma Make wireframe

  From there, I built a wireframe in Figma Make to test the tool and iterate through group brainstorming sessions.
  {% endwrap %}

{% endtwoCol %}

![AskFlow Agents design process: exploration, testing in production, Figma Make prototyping](/assets/cases/askflow/askflow-process.svg)

###### Testing & Iteration
## The turning point came when the experience moved from a crowded builder to a calmer, guided playground.

{% cardRow 2 %}

  {% wrap %}
  ### Before

  - Highly cluttered drag-and-drop canvas
  - Heavy visual blocks and noisy terminology
  - Confusing logic language such as “Reference Date”
  {% endwrap %}

  {% wrap %}
  ### After

  - Muted gray blocks and cleaner hierarchy
  - Contextual sidebar for data inputs
  - Simplified language such as “Reference Moment”
  {% endwrap %}

{% endcardRow %}

I ran two rounds of qualitative testing with internal staff and hotel clients. The clearest pain points were confusion around field names, hidden descriptions, and misunderstood conditional logic such as AND vs. OR.

![Tests with final users](/assets/cases/askflow/askflow-testing.svg)

###### The Solution
## A library-first activation experience paired with a calmer editor for advanced users.

{% cardRow 2 %}

  {% wrap %}
  ### Agent Showcase Library

  Users could browse validated AI agents and activate them in less than a minute with predefined settings.
  {% endwrap %}

  {% wrap %}
  ### Refined Contextual Editor

  The advanced editing surface stayed powerful but significantly less visually noisy, helping users focus on what mattered next.
  {% endwrap %}

{% endcardRow %}
